# Mostafa Ramadan — Portfolio

A responsive personal portfolio built with semantic HTML, CSS, and vanilla JavaScript.

## Run locally

From this directory, start a static server:

```powershell
python -m http.server 8000
```

Open <http://localhost:8000> in a browser. No build step or package install is required.

## Deploy

The site is published from the `main` branch root with GitHub Pages.

## Project structure

- `index.html` — page content and metadata
- `styles.css` — design tokens, layout, and responsive styles
- `script.js` — menu, typing effect, and scroll reveals
- `assets/` — locally stored icons, resume, and favicon
